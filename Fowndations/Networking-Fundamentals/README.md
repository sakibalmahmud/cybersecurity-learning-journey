
# Networking Fundamentals

## Overview

Networking Fundamentals is a foundational part of my cybersecurity learning journey. This section covers the core concepts of computer networking, helping me understand how devices communicate, exchange data, and interact across networks.

A strong understanding of networking is essential for cybersecurity, penetration testing, ethical hacking, network security, and bug bounty hunting.

## Learning Objectives

- Understand the fundamentals of computer networking.
- Learn how devices communicate within a network.
- Understand IP and MAC addressing.
- Explore the OSI Model and network communication layers.
- Learn about common network protocols and ports.
- Understand DNS and how domain name resolution works.
- Explore how routers forward data between networks.
