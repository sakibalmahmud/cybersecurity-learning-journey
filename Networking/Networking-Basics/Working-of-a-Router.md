# Working of a Router

A **router** is a networking device that connects different networks and forwards data packets between them using IP addresses.

### Key Functions of a Router

**1. Connects Networks:** Connects different networks, such as a home network to the internet.

**2. Forwards Data:** Directs data packets toward their correct destination using destination IP addresses.

**3. Assigns IP Addresses:** Uses DHCP (Dynamic Host Configuration Protocol) to automatically assign IP addresses to devices.

**4. Provides Network Security:** Helps protect the network through features such as firewalls and access controls.

**5. Manages Multiple Devices:** Allows multiple devices to share a single internet connection.

**6. Network Address Translation (NAT):** Translates private IP addresses into a public IP address, allowing multiple devices to access the internet using one public IP.

**7. Maintains a Routing Table:** Stores information about available routes and uses it to determine where data packets should be forwarded.

**8. Acts as a Default Gateway:** Provides a path for devices to communicate with networks outside their local network.

### How a Router Works

1. A device sends a data packet to another network.
2. The router receives the packet and checks its destination IP address.
3. It looks up the destination in its routing table.
4. It selects the appropriate route.
5. It forwards the packet toward its destination.

### Important Terms

- **LAN (Local Area Network):** A network that connects devices within a limited area, such as a home or office.
- **WAN (Wide Area Network):** A network that connects multiple networks over large geographical areas.
- **NAT:** Translates private IP addresses into public IP addresses and vice versa.
- **DHCP:** Automatically assigns IP addresses to network devices.
- **Routing Table:** Contains information about network destinations and available routes.
- **Default Gateway:** The router address that a device uses to reach external networks.
- **Routing Protocols:** Protocols such as OSPF and BGP that help routers learn and exchange routing information.
