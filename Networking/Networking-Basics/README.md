# Networking Basics

This folder contains my personal notes on computer networking, covering fundamental concepts, protocols, network devices, and communication methods.

The goal is to build a strong networking foundation for cybersecurity, ethical hacking, and bug bounty hunting.

## 📚 Topics Covered

- Introduction to Computer Networking
- Types of Networks (LAN, WAN, MAN, PAN)
- Network Topologies
- OSI Model
- TCP/IP Model
- IP Addressing (IPv4 and IPv6)
- Public IP vs Private IP
- MAC Address
- Subnetting
- Network Devices (Router, Switch, Hub, Firewall)
- DNS (Domain Name System)
- DHCP (Dynamic Host Configuration Protocol)
- NAT (Network Address Translation)
- TCP vs UDP
- Common Network Ports and Protocols
- Default Gateway
- Routing Basics

*More topics will be added as I continue learning.*

## 🎯 Learning Objectives

- Understand how computer networks communicate.
- Learn how data travels between devices and networks.
- Understand IP addressing, ports, and networking protocols.
- Build a foundation for network security and penetration testing.
- Develop practical networking skills through hands-on labs.

## 🌐 Recommended Learning Resources

These are some useful platforms and resources for learning networking:

| Resource | Description |
|---|---|
| **Cisco Networking Academy** | Structured networking courses and practical learning resources. |
| **TryHackMe** | Beginner-friendly networking rooms and hands-on cybersecurity labs. |
| **Practical Networking** | Clear explanations of networking concepts with practical examples. |
| **Professor Messer** | Free networking lessons, especially for CompTIA Network+. |
| **Wireshark** | Practical packet analysis and network traffic inspection. |
| **YouTube** | Additional tutorials and visual explanations of networking concepts. |

## 🛠️ Tools for Practice

- **Cisco Packet Tracer** – Simulate and practice network configurations.
- **Wireshark** – Capture and analyze network traffic.
- **Nmap** – Discover hosts, services, and open ports.
- **Linux Terminal** – Practice networking commands such as `ping`, `ip`, `traceroute`, `ss`, and `curl`.

## 📌 My Learning Approach

1. Learn the basic networking concepts.
2. Understand how each protocol and device works.
3. Practice using networking tools.
4. Complete hands-on labs on Cisco and TryHackMe.
5. Document important concepts and practical exercises.
