# OverTheWire – Bandit

This directory contains my hands-on learning notes and writeups from the **Bandit wargame by OverTheWire**.

Bandit is a beginner-friendly Linux-based wargame designed to help learners develop essential command-line skills and understand basic cybersecurity concepts through practical challenges.

## About Bandit

The Bandit wargame focuses on Linux fundamentals, command-line operations, file permissions, SSH, networking, and other essential system administration concepts.

Each level introduces a new challenge that requires problem-solving and practical use of Linux commands.

## Learning Areas

Throughout these challenges, I practice and develop knowledge in:

- Linux Command Line
- File and Directory Management
- Linux File Permissions
- SSH Authentication
- SSH Private Keys
- File Comparison and Analysis
- Data Encoding and Compression
- Networking Fundamentals
- Port Scanning
- TCP Connections
- SSL/TLS Encryption
- Linux System Administration
- Basic Shell Operations

## Learning Approach

For each challenge, I document:

1. The level goal and challenge requirements.
2. Commands and tools used.
3. Step-by-step problem-solving methods.
4. Important findings and results.
5. Key concepts learned from the challenge.

## Learning Objectives

- Build strong Linux command-line fundamentals.
- Improve problem-solving and troubleshooting skills.
- Understand basic networking and authentication techniques.
- Gain practical experience with Linux security concepts.
- Develop confidence in using Kali Linux and other Linux environments.
